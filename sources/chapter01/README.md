# Sumber Bab 01

Berkas pendukung Aktivitas dan Latihan Bab 01, Orientasi dan Bahasa Bersama
Cloud-Native. Seluruh berkas berupa Markdown agar mudah disalin ke folder tim dan
diisi tanpa perangkat lunak khusus.

| Berkas | Kegunaan |
| :-- | :-- |
| `templat-profil-organisasi.md` | Templat profil organisasi satu halaman, luaran pertama tonggak C1, dilengkapi contoh ringkas Medikara Health |
| `lembar-pemicu-modernisasi.md` | Lembar isian lima sampai sepuluh pemicu modernisasi beserta dampak, sistem terlibat, dan prioritas; dipakai pada Aktivitas dan Latihan 2 |
| `panduan-izin-dan-anonimisasi.md` | Panduan mengurus izin organisasi nyata, cara anonimisasi, etika wawancara, dan daftar periksa sebelum dokumen dikumpulkan |

Urutan pemakaian: baca panduan izin lebih dahulu, isi lembar pemicu selama
wawancara dan pemetaan sistem, lalu tulis profil organisasi sebagai ringkasan.
